# Satisfactory Phase Guide

A first-playthrough guide to Satisfactory 1.2, one Space Elevator phase at a time: milestones with costs and unlocks, build order, healthy production targets, and a Toolkit with a production planner and calculators.

It is a static site: upload these files to any web host (GitHub Pages works) and open `index.html`. On an iPad, open it in Safari and choose Share → Add to Home Screen to run it as a full-screen web app that also works offline.

Checklist progress and your starting area are saved on the device you use.

## Files

- `index.html`, `app.js`: the guide
- `ds/`: the Skeuo 2012 design system (styles, components, fonts)
- `manifest.webmanifest`, `sw.js`, `icons/`: Home Screen web app and offline support
